# Saudi NCA Essential Cybersecurity Controls (ECC) Mapping

## Overview

This project explores the Saudi National Cybersecurity Authority (NCA) Essential Cybersecurity Controls and their relationship to enterprise cybersecurity technologies and operational security practices.

The objective is to develop practical familiarity with cybersecurity governance and control implementation within the Saudi Arabian regulatory environment.

## Planned Areas

The project will examine controls related to areas such as:

- Identity and Access Management
- Privileged Access Management
- Authentication and MFA
- System and information protection
- Vulnerability management
- Security monitoring
- Logging and SIEM
- Endpoint security
- Data protection
- Backup and recovery
- Cybersecurity governance

## Technology Mapping

Where appropriate, controls will be mapped conceptually to technologies and security practices including:

- Microsoft Entra ID
- Active Directory
- WALLIX PAM
- Microsoft Sentinel
- Wazuh SIEM
- Nessus
- Endpoint security platforms
- MFA
- Backup and disaster recovery technologies

## Planned Deliverables

The project will contain:

- NCA ECC control mapping
- Security technology mapping
- Example implementation approaches
- Evidence examples
- IAM/PAM control mapping
- SIEM and monitoring control mapping
- Lessons learned

## Purpose

The purpose of this project is not to claim formal NCA compliance or auditing experience.

It is intended to demonstrate my understanding of how technical cybersecurity controls can support requirements within the Saudi cybersecurity regulatory environment.
