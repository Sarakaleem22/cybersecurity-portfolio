# Microsoft Entra Identity Security Lab

## Overview

This project documents my hands-on learning and implementation of identity and access security using Microsoft Entra ID.

The objective is to build an enterprise-style identity environment and apply modern Identity and Access Management (IAM) and Zero Trust principles.

## Planned Lab Areas

- User and group management
- Role-Based Access Control (RBAC)
- Authentication methods
- Multi-Factor Authentication (MFA)
- Conditional Access
- Self-Service Password Reset (SSPR)
- Identity Protection
- Enterprise applications and SSO
- Privileged Identity Management (PIM)
- Access reviews
- Identity governance
- Hybrid identity concepts
- Break-glass / emergency access
- Zero Trust identity controls

## Planned Architecture

The lab will simulate an enterprise environment with multiple departments and different levels of access requirements.

Example departments:

- IT
- Finance
- HR
- Management

Identity controls will be designed according to least-privilege and Zero Trust principles.

## Evidence

As the lab progresses, this repository will contain:

- Architecture diagrams
- Configuration screenshots
- Policy designs
- Identity scenarios
- Security decisions and explanations
- Lessons learned
