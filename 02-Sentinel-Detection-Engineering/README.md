# Microsoft Sentinel Detection Engineering Lab

## Overview

This project documents hands-on security monitoring, detection engineering, threat hunting, and incident investigation using Microsoft Sentinel and Kusto Query Language (KQL).

The objective is to develop practical SIEM skills while building on my professional experience working with Wazuh SIEM.

## Planned Lab Areas

- Microsoft Sentinel architecture
- Log ingestion and data connectors
- Windows security event monitoring
- KQL fundamentals
- Detection engineering
- Analytics rules
- Incident investigation
- Threat hunting
- MITRE ATT&CK mapping
- Security monitoring and alert tuning

## Planned Detection Scenarios

The lab will include detections for scenarios such as:

- Repeated authentication failures
- Brute-force activity
- Privileged group membership changes
- Suspicious PowerShell activity
- Account lockouts
- Unusual authentication activity

## Planned Deliverables

This project will eventually contain:

- 15+ KQL queries
- Detection and analytics rules
- MITRE ATT&CK mappings
- Incident investigation examples
- Threat-hunting queries
- Architecture diagrams
- Configuration screenshots
- Lessons learned

## Professional Context

I have professional experience deploying and operating Wazuh SIEM across enterprise environments, including log monitoring, detection-rule creation, alert tuning, and security-event analysis.

This lab is intended to expand that SIEM experience into Microsoft Sentinel and KQL.
